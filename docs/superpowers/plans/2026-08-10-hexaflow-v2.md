# HexaFlow v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a 12-page React + GSAP + react-three-fiber scroll-animation site that retells the HexaFlow engineering journey end to end, with whole-assembly and per-part 3D viewers and the new NASA Glenn 2.2s drop test.

**Architecture:** Vite SPA. A shared design system + scroll/3D primitives are built first (Tasks 0–3, sequential, by the lead). Then each page is built by a fanned-out subagent using only the shared components and data files (Tasks 4–15). Then integrate, verify headless, ingest assets, and push to GitHub on a `v2` branch (Tasks 16–18). Base-path-agnostic so one build serves Vercel/Netlify, GitHub Pages, and a future custom domain.

**Tech Stack:** Vite, React 18, react-router 6, GSAP 3 + ScrollTrigger, Lenis, react-three-fiber + drei, Tailwind CSS 3, three.js. Brand: dark `#060e1c`, gold `#d4a017`, Inter + Space Grotesk.

**Spec:** `docs/superpowers/specs/2026-08-10-hexaflow-v2-design.md`

- [ ] **Step 7: src/lib/withBase.js**

```js
// Prefix any root-absolute URL with the configured base path.
export const BASE = import.meta.env.BASE_URL || '/'
export function withBase(p) {
  if (!p) return BASE
  if (/^(https?:)?\/\//.test(p) || p.startsWith('data:')) return p
  return (BASE.endsWith('/') ? BASE : BASE + '/') + p.replace(/^\/+/, '')
}
export const ROUTE_BASE = (() => {
  const b = import.meta.env.BASE_URL || '/'
  return b === '/' ? '' : b.replace(/\/$/, '')
})()
```

- [ ] **Step 8: src/components/SmoothScroll.jsx (Lenis + GSAP)**

```jsx
import { useEffect, useRef } from 'react'
import Lenis from 'lenis'
import { gsap } from 'gsap'
import { ScrollTrigger } from 'gsap/ScrollTrigger'
import { useReducedMotion } from '../lib/useReducedMotion.js'

gsap.registerPlugin(ScrollTrigger)

export default function SmoothScroll({ children }) {
  const prefersReduced = useReducedMotion()
  useEffect(() => {
    if (prefersReduced) return
    const lenis = new Lenis({ duration: 1.1, smoothWheel: true })
    lenis.on('scroll', ScrollTrigger.update)
    const raf = (t) => { lenis.raf(t); requestAnimationFrame(raf) }
    const id = requestAnimationFrame(raf)
    return () => { lenis.destroy(); cancelAnimationFrame(id) }
  }, [prefersReduced])
  return <>{children}</>
}
```

- [ ] **Step 9: src/lib/useReducedMotion.js**

```js
import { useEffect, useState } from 'react'
export function useReducedMotion() {
  const [reduced, setReduced] = useState(false)
  useEffect(() => {
    const mq = window.matchMedia('(prefers-reduced-motion: reduce)')
    const on = () => setReduced(mq.matches)
    on()
    mq.addEventListener('change', on)
    return () => mq.removeEventListener('change', on)
  }, [])
  return reduced
}
```

- [ ] **Step 10: src/components/ScrollProgress.jsx**

```jsx
import { useEffect, useRef } from 'react'
import { gsap } from 'gsap'
import { ScrollTrigger } from 'gsap/ScrollTrigger'
gsap.registerPlugin(ScrollTrigger)
export default function ScrollProgress() {
  const ref = useRef(null)
  useEffect(() => {
    const el = ref.current
    const st = ScrollTrigger.create({
      start: 0, end: 'max',
      onUpdate: (self) => { gsap.set(el, { scaleX: self.progress }) }
    })
    return () => st.kill()
  }, [])
  return <div ref={ref} className="fixed top-0 left-0 z-50 h-1 w-full origin-left bg-hex-gold" style={{ transform: 'scaleX(0)' }} />
}
```

- [ ] **norm.js:** The glTF node-name normalization from the old site (spaces→`_`, strip `.` and `/`) applied to both sides before `includes`. Pure function.

```js
// src/components/threed/norm.js
export const norm = (s) =>
  String(s).replace(/\s+/g, '_').replace(/[./]/g, '')
export const matches = (nodeName, glMatch) =>
  glMatch.some((m) => norm(nodeName).includes(norm(m)))
```

- [ ] **ModelViewer.jsx:** Generic R3F + drei viewer. Props: `src` (glb/gltf/stl url), `isolate` (optional glMatch array), `autoRotate`, `explode`, `wireframe`, `labels`, `className`.
