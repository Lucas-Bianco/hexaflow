Drop all your image files into this folder (public/images/).

Once a file is here, reference it in any page as:
  /images/yourfilename.jpg

Example: if you add "tdc-photo.jpg" here, use it like this in any .astro file:
  <img src="/images/tdc-photo.jpg" alt="TDC module" style="width:100%;border-radius:0.75rem;" />
